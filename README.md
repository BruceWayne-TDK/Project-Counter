# React Counter App

A simple, interactive counter application built with **React** and **Vite**. Features a clean UI to increment, decrement, and reset the counter value using React state hooks.

## Features

* **Increment (`+`)**: Increases the current count by 1.
* **Decrement (`-`)**: Decreases the current count by 1.
* **Reset (`Reset`)**: Resets the count back to 0.

## Tech Stack

* **React** (useState hook for state management)
* **Vite** (Build tool)
* **CSS** (Custom styling)
